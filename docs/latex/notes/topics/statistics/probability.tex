\section{Probability}

\subsection{Derangement and Permutation}

A \textbf{permutation} is an arrangement of all members of a set into some sequence or order. The number of permutations of $n$ distinct objects is:
\[ P(n) = n! \]

For permutations taken $r$ at a time:
\[ P(n, r) = \frac{n!}{(n-r)!} \]

A \textbf{derangement} is a permutation where no element appears in its original position. The number of derangements of $n$ elements is:
\[ D(n) = n! \sum_{i=0}^{n} \frac{(-1)^i}{i!} \approx \frac{n!}{e} \]

Recurrence relation: $D(n) = (n-1)[D(n-1) + D(n-2)]$

\subsection{Bayes' Theorem}

Bayes' Theorem describes the probability of an event based on prior knowledge of conditions related to that event:
\[ P(A \mid B) = \frac{P(B \mid A) \cdot P(A)}{P(B)} \]

Where:
\begin{itemize}
  \item $P(A \mid B)$ = posterior probability (probability of $A$ given $B$)
  \item $P(B \mid A)$ = likelihood (probability of $B$ given $A$)
  \item $P(A)$ = prior probability (initial probability of $A$)
  \item $P(B)$ = evidence (total probability of $B$)
\end{itemize}

For multiple events, the law of total probability gives:
\[ P(B) = \sum_{i=1}^{n} P(B \mid A_i) P(A_i) \]

\subsection{Random Variables and Distributions}

\subsubsection{Bernoulli}

A Bernoulli distribution models a single trial with two possible outcomes (success/failure). Parameter: $p$ (probability of success).

\textbf{PMF:} $P(X = k) = p^k(1-p)^{1-k}$ for $k \in \{0, 1\}$

\textbf{Mean:} $\mathbb{E}[X] = p$

\textbf{Variance:} $\text{Var}(X) = p(1-p)$

\subsubsection{Binomial}

The binomial distribution models the number of successes in $n$ independent Bernoulli trials. Parameters: $n$ (number of trials), $p$ (probability of success).

\textbf{PMF:} $P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}$ for $k = 0, 1, \ldots, n$

\textbf{Mean:} $\mathbb{E}[X] = np$

\textbf{Variance:} $\text{Var}(X) = np(1-p)$

\subsubsection{Poisson}

The Poisson distribution models the number of events occurring in a fixed interval of time or space. Parameter: $\lambda$ (average rate of occurrence).

\textbf{PMF:} $P(X = k) = \frac{e^{-\lambda} \lambda^k}{k!}$ for $k = 0, 1, 2, \ldots$

\textbf{Mean:} $\mathbb{E}[X] = \lambda$

\textbf{Variance:} $\text{Var}(X) = \lambda$

Note: Poisson approximates Binomial when $n$ is large and $p$ is small, with $\lambda = np$.

\subsubsection{Geometric}

The geometric distribution models the number of trials until the first success. Parameter: $p$ (probability of success).

\textbf{PMF:} $P(X = k) = (1-p)^{k-1}p$ for $k = 1, 2, 3, \ldots$

\textbf{Mean:} $\mathbb{E}[X] = \frac{1}{p}$

\textbf{Variance:} $\text{Var}(X) = \frac{1-p}{p^2}$

\textbf{Memoryless property:} $P(X > m + n \mid X > m) = P(X > n)$

\subsubsection{Normal}

The normal (Gaussian) distribution is continuous and symmetric around its mean. Parameters: $\mu$ (mean), $\sigma^2$ (variance).

\textbf{PDF:} $f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$

\textbf{Mean:} $\mathbb{E}[X] = \mu$

\textbf{Variance:} $\text{Var}(X) = \sigma^2$

\textbf{Standard normal:} $Z = \frac{X - \mu}{\sigma}$ follows a normal distribution with $\mu = 0$ and $\sigma = 1$.

\textbf{68-95-99.7 rule:} Approximately 68\% of data falls within $\pm 1\sigma$, 95\% within $\pm 2\sigma$, and 99.7\% within $\pm 3\sigma$.
